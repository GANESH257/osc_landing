# OSC Landing Page

Landing page for Online Spine Care - Dr. Amit Bhandarkar's spine surgery practice in Chesterfield, MO.

## Features

- Responsive landing page design
- Contact form with email integration
- Newsletter subscription
- Brochure download functionality
- Google Sheets integration for form submissions
- Google Analytics integration

## Technologies Used

- PHP
- Bootstrap 5
- jQuery
- AOS (Animate On Scroll)
- Owl Carousel
- Google Sheets API

## Setup

1. Configure credentials in `includes/credentials/credentials.json` (not included in repo for security)
2. Set up email configuration in `includes/mail.php`
3. Deploy to your web server
